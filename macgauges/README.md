# Кольца машины (MacGauges)

Тихое приложение для macOS на Apple Silicon: нагрузка машины кольцами в строке меню.

| Кольцо | Что показывает |
|---|---|
| G (красное) | загрузка видеокарты, % |
| M (синее) | занятая оперативная память, % |
| C (белое) | загрузка процессора, % |
| V (зелёное) | память, которую держит видеокарта, % от всей |
| P (пурпурное) | потребляемая мощность всего Mac, Вт; полный круг — полная мощность устройства |
| Wi-Fi | дробь: загрузка сверху (зелёная), выгрузка снизу (красная), Мбит/с |

Числа обновляются раз в 2 секунды, без `sudo`. Режимы «Кольца» и «Числа», выбор колец и запуск при входе — в «Настройки…».
Есть виджет (малый и средний), но он показывает снимок раз в несколько минут — живые числа только в строке меню.

## Поставить
1. Скачать `MacGauges-1.0.dmg` из [релиза macgauges-v1.0](https://github.com/AiPetDevs/App/releases/tag/macgauges-v1.0).
2. Открыть DMG и перетащить «MacGauges» в «Программы».
3. Приложение подписано без Apple ID (ad-hoc), поэтому при первом запуске macOS его заблокирует:
   «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Или в Терминале:
   ```
   xattr -dr com.apple.quarantine /Applications/MacGauges.app
   ```

Требования: macOS 14 или новее, Apple Silicon. Проверено на MacBook Pro 16″ M4 Max, macOS 26.

## Честно о числах
- **P**: полный круг — 140 Вт для MacBook Pro 16″ M4 Max / M4 Pro (штатный блок Apple); на других Mac — мощность подключённого блока, без блока — 100 Вт. Под полной нагрузкой M4 Max берёт больше 140 Вт (добирает из батареи) — тогда кольцо полное и в подсказке «перегрузка».
- **Wi-Fi**: считается только интерфейс Wi-Fi; трафик по кабелю или через iPhone по USB не попадает.

Проверка подлинности DMG: SHA-256 указан в `update.json`.
